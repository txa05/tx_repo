# Portfólio de Tx

Portfólio pessoal de Tx, desenvolvido com Next.js, React e Tailwind CSS.

## Executar localmente

Requer Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

## Contacto

O formulário de contacto envia mensagens por SMTP quando as variáveis abaixo estão configuradas. Sem estas variáveis, o formulário continua disponível, mas não envia emails.

```env
MAIL_HOST=
MAIL_USER=
MAIL_PASS=
MAIL_FROM=
MAIL_TO=
```

Antes de publicar, substitua os placeholders de GitHub, LinkedIn, Instagram, email e domínio presentes no código.
